# Expense-Tracker
GUI-based application to track and manage expenses. Still being worked on right now.

## Features
Add and save expenses (date, category, description, amount).
View all record expenses in a dynamic text area.
Persistent storage using CSV

## Technologies Used
Python
Tkinter
SQL
PostgreSQL

## Future Improvements
Add data visualization for spending trends.
Integrate a database for better storage.
Create possible negative values for payment.
Cleaning up the code.
